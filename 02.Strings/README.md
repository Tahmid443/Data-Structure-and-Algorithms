# String in C

This folder contains basic **String** programs implemented in **C**. The programs are written in a simple, beginner-friendly, and exam-oriented style to help understand string manipulation and common string algorithms.

## 📚 Topics Covered

* String Input & Output
* String Length
* String Copy
* String Concatenation
* String Comparison
* String Reverse
* Palindrome Check
* Vowel and Consonant Count
* Character Frequency
* Uppercase to Lowercase Conversion
* Lowercase to Uppercase Conversion
* String Search
* Manual String Operations (Without Built-in Functions)


## 🚀 Features

* Written in **C Language**
* Beginner-Friendly Code
* Exam-Oriented Implementations
* Simple Logic with Proper Comments
* Covers Common String Operations

## 📖 Concepts

* String Declaration
* Character Arrays
* Null Character (`'\0'`)
* Built-in String Functions (`strlen`, `strcpy`, `strcmp`, `strcat`)
* Manual String Manipulation
* Character Processing

## 🎯 Learning Objectives

After completing these programs, you will be able to:

* Understand how strings are stored in C.
* Perform common string operations.
* Implement string algorithms without built-in functions.
* Solve basic string-related programming problems.
* Build a strong foundation for Data Structures and Algorithms (DSA).
