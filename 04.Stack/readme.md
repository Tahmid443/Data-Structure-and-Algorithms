# Stack in C

This folder contains basic **Stack** programs implemented in **C** using **structures** and **dynamic memory allocation**. The programs are simple, beginner-friendly, and designed for university lab exams and Data Structures & Algorithms (DSA) practice.

## 📚 Topics Covered

* Stack Implementation
* Push Operation
* Pop Operation
* Peek Operation
* Display Stack
* Check if Stack is Empty
* Check if Stack is Full
* Valid Parentheses Problem
* Infix to Postfix Conversion
* Postfix Expression Evaluation

## 🚀 Features

* Written in **C Language**
* Uses **Structures**
* Uses **Dynamic Memory Allocation (`malloc` & `free`)**
* Beginner-Friendly Code
* Exam-Oriented Implementations
* Well-Commented Programs

## 📖 Concepts

* Stack (LIFO - Last In, First Out)
* Dynamic Memory Allocation
* Push
* Pop
* Peek
* Stack Overflow
* Stack Underflow
* Expression Handling
* Parentheses Matching

## 🎯 Learning Objectives

After completing these programs, you will be able to:

* Understand the LIFO principle of a stack.
* Implement stack operations using structures and dynamic memory allocation.
* Solve common stack-based problems.
* Work with expression conversion and evaluation.
* Build a strong foundation for Data Structures and Algorithms (DSA).
