# Heap in C

This folder contains basic **Heap** programs implemented in **C** using **structures** and **dynamic memory allocation**. The programs are written in a simple, beginner-friendly, and exam-oriented style for learning Data Structures and Algorithms (DSA).

## 📚 Topics Covered

* Heap Implementation
* Max Heap
* Min Heap
* Heapify
* Build Max Heap
* Build Min Heap
* Heap Insertion
* Heap Deletion
* Heap Sort
* Priority Queue (Heap-Based)

## 🚀 Features

* Written in **C Language**
* Uses **Structures**
* Uses **Dynamic Memory Allocation (`malloc` & `free`)**
* Beginner-Friendly Code
* Exam-Oriented Implementations
* Well-Commented Programs

## 📖 Concepts

* Complete Binary Tree
* Max Heap
* Min Heap
* Heapify
* Build Heap
* Insert
* Delete
* Heap Sort
* Priority Queue

## 🎯 Learning Objectives

After completing these programs, you will be able to:

* Understand the structure and properties of a Heap.
* Implement Max Heap and Min Heap using structures and dynamic memory allocation.
* Perform insertion and deletion operations efficiently.
* Learn the Heapify process and build heaps from arrays.
* Implement Heap Sort and understand its time complexity.
* Build a strong foundation for Priority Queues and advanced Data Structures.
