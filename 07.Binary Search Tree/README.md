# Binary Search Tree (BST) in C

This folder contains basic **Binary Search Tree (BST)** programs implemented in **C** using **structures** and **dynamic memory allocation**. The programs are written in a simple, beginner-friendly, and exam-oriented style for learning Data Structures and Algorithms (DSA).

## 📚 Topics Covered

* Binary Search Tree (BST) Implementation
* Node Creation
* Insertion
* Deletion
* Searching
* Inorder Traversal
* Preorder Traversal
* Postorder Traversal
* Finding Minimum Element
* Finding Maximum Element
* Tree Height
* Counting Nodes

## 🚀 Features

* Written in **C Language**
* Uses **Structures**
* Uses **Dynamic Memory Allocation (`malloc` & `free`)**
* Beginner-Friendly Code
* Exam-Oriented Implementations
* Well-Commented Programs

## 📖 Concepts

* Binary Search Tree (BST)
* Tree Nodes
* Recursive Algorithms
* Dynamic Memory Allocation
* Tree Traversals
* Searching
* Insertion
* Deletion
* Height Calculation
* Minimum & Maximum Elements

## 🎯 Learning Objectives

After completing these programs, you will be able to:

* Understand the structure and properties of a Binary Search Tree.
* Implement BST operations using structures and dynamic memory allocation.
* Perform tree traversals using recursion.
* Insert, search, and delete nodes efficiently.
* Build a strong foundation for Trees and advanced Data Structures.
