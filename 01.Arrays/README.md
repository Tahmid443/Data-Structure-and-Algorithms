# Array in C

This folder contains basic **Array** programs implemented in **C** using **structures** and **dynamic memory allocation**. These programs are written in a simple and beginner-friendly style for learning, practice, and university lab exams.

## 📚 Topics Covered

* Array Creation
* Dynamic Memory Allocation (`malloc`)
* Array Traversal (Display)
* Array Insertion
* Array Deletion
* Array Update
* Linear Search
* Binary Search
* Time Complexity Basics

## 🚀 Features

* Written in **C Language**
* Uses **Structures**
* Uses **Dynamic Memory Allocation**

## 📖 Concepts

### Linear Search

* Works on both sorted and unsorted arrays.
* Time Complexity: **O(n)**

### Binary Search

* Works only on **sorted arrays**.
* Time Complexity: **O(log n)**

## 🎯 Learning Objectives

After completing these programs, you will be able to:

* Understand array memory allocation.
* Perform common array operations.
* Implement searching algorithms.
* Analyze the time complexity of array operations.
* Build a strong foundation for Data Structures and Algorithms (DSA).
