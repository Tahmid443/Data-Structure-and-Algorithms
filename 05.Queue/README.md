# Queue in C

This folder contains basic **Queue** programs implemented in **C** using **structures** and **dynamic memory allocation**. The programs are written in a simple, beginner-friendly, and exam-oriented style for learning Data Structures and Algorithms (DSA).

## 📚 Topics Covered

* Queue Implementation
* Enqueue Operation
* Dequeue Operation
* Front Operation
* Rear Operation
* Display Queue
* Check if Queue is Empty
* Check if Queue is Full
* Circular Queue
* Queue using Dynamic Array

## 🚀 Features

* Written in **C Language**
* Uses **Structures**
* Uses **Dynamic Memory Allocation (`malloc` & `free`)**
* Beginner-Friendly Code
* Exam-Oriented Implementations
* Well-Commented Programs

## 📖 Concepts

* Queue (FIFO - First In, First Out)
* Dynamic Memory Allocation
* Enqueue
* Dequeue
* Front
* Rear
* Queue Overflow
* Queue Underflow
* Circular Queue

## 🎯 Learning Objectives

After completing these programs, you will be able to:

* Understand the FIFO principle of a queue.
* Implement queue operations using structures and dynamic memory allocation.
* Learn the difference between a simple queue and a circular queue.
* Solve basic queue-related programming problems.
* Build a strong foundation for Data Structures and Algorithms (DSA).
