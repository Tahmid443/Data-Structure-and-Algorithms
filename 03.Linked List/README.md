# Linked List in C

This folder contains basic **Linked List** programs implemented in **C** using **structures** and **dynamic memory allocation**. The programs are designed to be simple, beginner-friendly, and suitable for university lab exams and DSA practice.

## 📚 Topics Covered

* Singly Linked List
* Node Creation
* Traversal (Display)
* Insertion at Beginning
* Insertion at End
* Insertion at Any Position
* Deletion from Beginning
* Deletion from End
* Deletion from Any Position
* Searching
* Updating Node Data
* Counting Nodes
* Reversing a Linked List

## 🚀 Features

* Written in **C Language**
* Uses **Structures**
* Uses **Dynamic Memory Allocation (`malloc` & `free`)**
* Beginner-Friendly Code
* Exam-Oriented Implementations
* Well-Commented Programs

## 📖 Concepts

* Linked List
* Node Structure
* Pointer Manipulation
* Dynamic Memory Allocation
* Traversal
* Insertion
* Deletion
* Searching
* Memory Management

## 🎯 Learning Objectives

After completing these programs, you will be able to:

* Understand the working of linked lists.
* Create and manage nodes dynamically.
* Perform insertion and deletion operations.
* Traverse and manipulate linked lists efficiently.
* Build a strong foundation for Data Structures and Algorithms (DSA).
